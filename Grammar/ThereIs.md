# Сказуемое, оборот There is (are)

## lesson1 Grammar There is (are)

### Когда используется

Используется для выражения наличия или существования в определенном месте📍или времени ⏳, лица 👤 или предмета 🔴, еще неизвестного собеседнику.

**В значении:**

- имеется
- находится
- есть
- существует

---

### Перевод

**Позиция:**

> `There is + Подлежащее + Обстоятельство.`

**Перевод на русский:**
Начиная с обстоятельства места или времени:

- **There is** an apple **on the table**.
  - На столе есть яблоко.
- **There was** a meeting **yesterday**.
  - Вчера была встреча.

---

### Другие времена

Глагол to be в обороте there is может употребляться разных в формах времени:

- **there is (are)** — есть, находится
- **there was (were)** — был, находился
- **there has been** — был, имелся
- **there will be** — будет

---

### Отрицательные форма с no

> **There is/are + no + существительное + обстоятельство.**

- Строятся при помощи местоимения **no**
- **no** стоит перед сущ.
- сущ. без артикля и без местоимения **any**

**There was no meeting yesterday.**
_Вчера не было встречи._

| Форма                                  | Пример                            | Перевод                |
| -------------------------------------- | --------------------------------- | ---------------------- |
| **There is no + ед. число**            | There is no coffee in the cup.    | В чашке нет кофе.      |
| **There is no + неисчисляемое**        | There is no water in the bottle.  | В бутылке нет воды.    |
| **There are no + мн. число**           | There are no chairs in the room.  | В комнате нет стульев. |
| **There was no + ед./неисчисляемое**   | There was no meeting yesterday.   | Вчера не было встречи. |
| **There were no + мн. число**          | There were no people here.        | Здесь не было людей.   |
| **There will be no + существительное** | There will be no lesson tomorrow. | Завтра не будет урока. |
