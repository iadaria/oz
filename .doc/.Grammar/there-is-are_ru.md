# There is / There are — теория

## 1. Значение

Конструкция **there is / there are** означает, что кто-то или что-то существует или находится в определённом месте/времени. Слово **there** здесь обычно не переводится отдельно: смысл передаётся как «есть», «имеется», «находится».

- **There is an apple on the table.** — На столе есть яблоко.
- **There are two books in the bag.** — В сумке находятся две книги.

## 2. Утвердительная форма

Порядок слов:

> **There + is/are + подлежащее + обстоятельство места или времени.**

| Существительное | Формула | Пример |
|---|---|---|
| Единственное число | **There is + a/an + существительное** | There is a cat in the room. |
| Множественное число | **There are + существительное во множественном числе** | There are three cats in the room. |
| Неисчисляемое | **There is + неисчисляемое существительное** | There is some water in the bottle. |

В разговорной речи **there is** часто сокращается до **there’s**. Сокращения *there’re* в стандартном английском обычно избегают.

## 3. Отрицательная форма

Отрицание образуется добавлением **not** после **is/are**:

- **There is not** → **There isn’t / There’s not**.
- **There are not** → **There aren’t**.

Примеры:

- **There isn’t a meeting today.** — Сегодня нет собрания.
- **There aren’t any chairs here.** — Здесь нет стульев.
- **There is no milk in the fridge.** — В холодильнике нет молока.
- **There are no tickets left.** — Билетов не осталось.

С неисчисляемыми существительными используется **there isn’t any + существительное**: *There isn’t any coffee.*

## 4. Вопросительная форма

В вопросе **is/are** ставится перед **there**:

- **Is there a pharmacy nearby?** — Поблизости есть аптека?
- **Is there any milk?** — Есть молоко?
- **Are there any questions?** — Есть вопросы?

Краткие ответы:

- **Yes, there is. / No, there isn’t.**
- **Yes, there are. / No, there aren’t.**

Нельзя отвечать *Yes, there’s* как стандартным кратким ответом.

## 5. Другие времена

В конструкции меняется глагол **be**:

| Время | Единственное число | Множественное число |
|---|---|---|
| Present | there is | there are |
| Past | there was | there were |
| Present perfect | there has been | there have been |
| Future | there will be | there will be |

Примеры:

- **There was a meeting yesterday.** — Вчера было собрание.
- **There were many people at the concert.** — На концерте было много людей.
- **There has been an error.** — Произошла ошибка.
- **There will be a test tomorrow.** — Завтра будет тест.

## 6. There is/are и обычное подлежащее

Сравните:

- **There is an apple on the table.** — На столе есть яблоко. Мы сообщаем о наличии яблока.
- **The apple is on the table.** — Яблоко находится на столе. Мы говорим о конкретном, уже известном яблоке.

## 7. Типичные ошибки

- Неправильно: *There are a book on the desk.* Правильно: **There is a book on the desk.**
- Неправильно: *There is two computers.* Правильно: **There are two computers.**
- Неправильно: *Is there books here?* Правильно: **Are there books here?**
- Неправильно: *There isn’t books.* Правильно: **There aren’t any books.**
- После **there is** с исчисляемым существительным в единственном числе нужен артикль: **There is a problem**, не *There is problem*.

## 8. Мини-проверка

Вставьте **is, are, was, were**:

1. There ___ an apple on the table.
2. There ___ three files in the folder.
3. There ___ a meeting yesterday.
4. ___ there any mistakes?

Ответы: **1 is, 2 are, 3 was, 4 Are.**
